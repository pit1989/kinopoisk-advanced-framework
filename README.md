# Kinopoisk Advanced QA Automation Framework

Высокоуровневый тестовый фреймворк на Python для автоматизации тестирования сценариев Кинопоиска. Проект демонстрирует современные подходы к разделению UI и API тестирования, а также изоляцию фронтенда через сетевые моки.

## 🛠 Архитектурные решения и особенности

Реальный сайт Кинопоиска защищен антифрод-системами (Cloudflare / SmartCaptcha). Чтобы обойти блокировки роботов и обеспечить 100% стабильность тестов (Flaky-free), в проекте реализован **гибридный подход**:

1. **UI Изоляция (Network Mocking):** Тестирование интерфейса полностью изолировано от реального бэкенда. С помощью `page.route` в Playwright перехватываются внутренние API-запросы приложения, а вместо них подставляются заготовленные локальные JSON-шаблоны (Mocks). Это позволяет мгновенно тестировать редкие сценарии (например, ошибки сервера 500), не нагружая реальную сеть.
2. **Page Object Model (POM):** Логика взаимодействия со страницами вынесена в отдельные классы-контроллеры, что изолирует структуру тестов от изменений в верстке сайта.
3. **API Тестирование:** Проверка контрактов бэкенда вынесена в отдельный слой тестов с использованием библиотеки `requests`, что демонстрирует навыки работы с REST API без открытия тяжелого браузера.

## 📁 Структура проекта

```text
kinopoisk-advanced-framework/
│
├── pages/                  # Классы страниц (Page Object Model)
│   └── movie_page.py       # Локаторы и методы взаимодействия со страницей фильма
│
├── mocks/                  # Тестовые данные для подмены ответов сервера
│   ├── movie_success.json  # Успешный ответ (код 200)
│   └── movie_404.json      # Ошибка сервера или ресурса
│
├── tests/                  # Тестовые сценарии
│   ├── test_ui_search.py   # UI-тесты с перехватом сетевых запросов
│   └── test_api_backend.py # Чистые API-тесты бэкенда
│
├── .gitignore              # Исключение кэша Python (__pycache__) из индекса Git
├── conftest.py             # Глобальные фикстуры pytest для инициализации страниц
└── requirements.txt        # Список зависимостей проекта
```

## 📦 Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com/pit1989/kinopoisk-advanced-framework
   cd kinopoisk-advanced-framework
   ```

2. Установите зависимости и браузерные бинарники Playwright:
   ```bash
   pip install -r requirements.txt
   playwright install
   ```

3. Запустите все тесты:
   ```bash
   pytest tests/
   ```

4. Запустите UI-тесты в режиме с отображением браузера (headed):
   ```bash
   pytest tests/test_ui_search.py --headed
   ```
